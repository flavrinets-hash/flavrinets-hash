### Проекты

#### [Telegram Webhook API: Integration & Docs-as-Code](https://github.com/flavrinets-hash/Telegram_OpenAPI)
Руководство и архитектурный шаблон безопасной доставки вебхуков Telegram Bot API через веб-сервер Nginx со спецификацией OpenAPI 3.0.

* **Реализация:**
  * Проектирование спецификации OpenAPI 3.0 и Swagger UI для методов управления вебхуками и событий `Update`.
  * Конфигурация Nginx: reverse proxy, SSL-терминация, проверка токена безопасности `X-Telegram-Bot-Api-Secret-Token`.
  * Разработка структуры документации по фреймворку Diátaxis (Reference, How-To, глоссарий, архитектурные схемы).
  * Настройка автоматической сборки документации на GitHub Pages и линтинга Markdown через GitHub Actions.
* **Стек:** OpenAPI 3.0, Swagger UI, MkDocs Material, Nginx, Mermaid, Draw.io, GitHub Actions
